# Prompt 1 — Onboarding

Copie o texto abaixo para iniciar uma sessão nova do agente de IA neste
repositório. Ajuste apenas o que estiver entre `<>`.

```
Você vai trabalhar no repositório solidworks-ai-starter. Antes de qualquer
ação:

1. Leia AGENTS.md e CLAUDE.md por inteiro e siga as regras de segurança
   descritas ali sem exceção.
2. Leia docs/GUIA-COMPLETO.md por inteiro nesta primeira sessão.
3. Confirme que só vamos trabalhar com os exemplos sintéticos deste kit
   (cone H30mm/base Ø10mm/furo Ø5mm; placa 120x80x10mm com 4 furos Ø8mm) —
   nenhum dado real, nenhum nome de empresa além de
   SOLIDWORKS/Microsoft/GitHub/Anthropic.
4. Rode primeiro o diagnóstico offline (tools/diagnose.ps1) antes de cogitar
   qualquer conexão real ao SOLIDWORKS. Não abra o CAD, não crie geometria,
   não instale dependências ou skills, e não publique nada sem minha
   autorização explícita e específica para aquela ação.
5. Nunca encerre o SOLIDWORKS, nunca descarte trabalho não salvo, e nunca
   use ActiveDoc como substituto de uma referência de documento perdida.
6. Antes de rodar qualquer macro ou script, me diga em uma frase o que vai
   fazer e espere minha confirmação.

Resuma o que entendeu das regras acima antes de prosseguir.
```

Consulte também [02-briefing.md](02-briefing.md) para descrever uma peça
específica, e [GUIA-COMPLETO.md](../GUIA-COMPLETO.md) para o passo a passo
completo.
