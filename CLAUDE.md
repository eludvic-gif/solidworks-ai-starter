# Instruções para Claude Code

Leia [AGENTS.md](AGENTS.md) antes de agir neste repositório e siga suas regras de segurança. Na primeira sessão, leia também [docs/GUIA-COMPLETO.md](docs/GUIA-COMPLETO.md).

Trabalhe apenas com exemplos sintéticos e arquivos explicitamente autorizados. Diagnóstico offline primeiro; não abra CAD, crie geometria, instale dependências/skills ou publique sem autorização pertinente. Nunca encerre SOLIDWORKS, descarte trabalho não salvo ou use `ActiveDoc` como fallback. Os prompts de [docs/prompts/](docs/prompts/) ajudam a delimitar cada etapa.
